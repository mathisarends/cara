# gateway-client

Fully typed, code-generated Python client for the Cara Gateway's JSON-RPC 2.0
WebSocket API. Models, namespace clients, and the top-level client class are
generated by `rpckit`'s codegen from
`gateway/server/schema/gateway.openrpc.json` — see
[`gateway-codegen`](../codegen). It has no dependency on the `gateway-server`
package itself, only `rpckit`, `pydantic`, and `websockets`, so any process
that can reach the Gateway over WebSocket ([`cli`](../../cli), the voice
pipeline, a future channel) can depend on this package alone.

```python
transport = await WebSocketTransport.connect(url, token=token)
async with GatewayClient(transport) as client:
    session = await client.session.open(channel={"name": "cli"})
    await client.turn.start(session_id=session.id, message="Hallo")
    async for notification in client.notifications():
        ...
```

Methods are namespaced by RPC prefix (`client.session.*`, `client.turn.*`,
...), keyword-only, and return parsed Pydantic models. Errors:
`RpcRemoteError` (server returned a JSON-RPC error), `RpcTransportError`
(connection dropped while a request was pending) — both from `rpckit.client`,
re-exported here.

## Regenerating

Whenever the Gateway's RPC surface changes:

```bash
uv run cara-gateway-schema
uv run --package gateway-codegen cara-gateway-client-generate \
  gateway/server/schema/gateway.openrpc.json
```

Every file under `src/gateway_client/` is generated and must not be edited by
hand.

## Dependencies

- Generated from [`gateway-server`](../server)'s OpenRPC schema by
  [`gateway-codegen`](../codegen).
- Consumed by [`cli`](../../cli) and `voice.llm.GatewayAgentSession`.
